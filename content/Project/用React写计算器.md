# New

网格布局用grid
	grid-template-columns/rows ：可以指定多少行多少列，每一列/行多大多小
	gap: 2px;间隔
	grid-column: span 2;横向填补两个方格
灵活布局 flex
	先要指定用flex：display：flex
	flex-direction：column 用列作为主轴（axis）
模糊匹配className可以这样写：
	``[class^="block-"]``
