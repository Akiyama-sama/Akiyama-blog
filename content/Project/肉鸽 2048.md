# 肉鸽 2048 · PRD（MVP v0.1）

> 状态：粗稿 v0.2 · 范围：仅 MVP（题材换皮、日挑战/社交裂变暂缓，见 §9）· §12 已回填小丑牌设计研究，§4/§5/§6/§7 已按研究校准
> 上游笔记：[[小游戏]] ｜ 竞品查新结论：Steam 端已红海（Numbers Go Up / Tiles & Vials / Merge Maestro / 肉鸽2048），微信小游戏生态内该品类近乎空白 → 差异化立足点。

## 1. 一句话定位

滑动 2048 的手感 + 小丑牌式的构筑成长：数字方块可被「附魔」，Boss 会攻击棋盘，关卡目标分数指数上涨，玩家用规则改写类道具去突破数学。

## 2. 核心循环

```
进入关卡 → 目标分数展示
   ↓
滑动合成（回合制：每滑一次=1回合，Boss 与附魔按回合结算）
   ↓
达到目标分 → 通关 → 获得 金钱 + 附魔奖励
   ↓
关卡间商店（买附魔/升级/刷新）→ 下一关（目标分上涨）
   ↓
失败 → 看广告复活（清行动一次）或 整局重来
```

- 一局 = 3 章 ×（3 普通关 + 1 Boss 关）= 12 关，全程约 25–40 分钟。
- 整局为一次 run，死局/失败即 run 结束（肉鸽性），但商店道具跨关保留。

## 3. 基础规则（与经典 2048 的差异）

| 项 | 规则 |
|---|---|
| 棋盘 | 4×4，新方块每回合在空位出现，2（90%）/ 4（10%） |
| 回合 | 每次有效滑动 = 1 回合；无有效移动不消耗回合 |
| 合成分 | **合成分 = 合成结果数字 × 当前倍率**（倍率来源：附魔、关卡加成） |
| 目标分 | 关卡开始给出，累计合成分达到即通关（不要求合出 2048） |
| 死局处理 | 棋盘满且无合法滑动 ≠ 立即失败 → 进入「死局状态」：可使用手牌/道具解局，或付费/看广告清行；解不开才判负 |

死局判定是关卡制的生命线：纯分控里死局=挫败，必须给 comeback 手段。

## 4. 关卡与目标分数曲线

- 目标分按指数上涨，构筑能力按多项式上涨——**玩家必须靠附魔突破指数**，这是小丑牌爽点的直接移植。
- 曲线草案（结构校准自 §12.1，数值待模拟）：
  - **前陡后缓**：章基础分第 1 章 500，章间倍率前 ×2.5 后 ×1.5——Balatro 实测并非恒定 1.6：ante 1→4 约 ×2.5/级、之后放缓到 ×1.4–1.8，恒定 1.6 只出现在无尽模式。前期快速抬高，教会玩家「线性堆分活不下去」。
  - **章内三段**：关1 = 章基础分 ×1、关2 = ×1.5、关3 = ×2，章末 Boss = ×2.5 且附加 Boss 规则。示例：第 1 章 500 / 750 / 1000 / 1250。
- 每关限回合：普通关 40 回合，Boss 关 50 回合（Boss 行为见 §6）。**剩余回合在结算时换钱**（见 §7）——省步=赚钱，防挂机的同时奖励高效。

## 5. 附魔系统（MVP 共 30 张）

设计铁律：**只做改规则，不做改数值**。「4 分变 6 分」是垃圾设计，「2+2=5」才是内容。

### 5.0 计分三档与槽位顺序（校准自 §12.1）

- 每步得分 = 合成基数 × Mult。附魔按效果分三档：**+基数**（加法粘合剂）、**+Mult**（线性成长）、**×Mult**（指数成长，获取门槛必须显著高于前两者）。
- **附魔槽位有顺序，结算从左到右**：先放 +Mult 再放 ×Mult，被乘的基数才大——摆放顺序本身是构筑资源（Balatro 结算管线的直接移植）。
- **稀有度 ≠ 强度**：N 卡里保留 1–2 张「Cavendish 式强卡」，廉价但能定义整局（见 §5.3 低语）。

### 5.1 稀有度与配比

| 稀有度 | 数量 | 定位 |
|---|---|---|
| N（普通） | 16 | 小幅倍率/条件触发，构筑粘合剂 |
| R（稀有） | 10 | 单条流派核心规则 |
| SR（史诗） | 4 | 改写棋盘基本法（棋盘形状、方块语义） |

商店抽卡权重 N:R:SR = 70:25:5；第 2 章起 SR 权重翻倍。

### 5.2 流派分组（商店按流派定向刷新，形成 Build 感）

- **倍率流**：无脑堆 mult，稳但上限低（新手保底流派）
- **低阶流**：围绕 2/4/奇数做文章，棋盘会被奇数污染但分数爆炸
- **空间流**：吃空格数/角落/贴边，考验棋盘管理
- **大数流**：养高数字方块，后期发力，前期容易暴毙

### 5.3 附魔示例（完整 30 张表进数值表文档，此处列代表作）

| 附魔 | 稀有度 | 流派 | 规则 |
|---|---|---|---|
| 首合成 | N | 倍率 | 每回合第一次合成 mult +3 |
| 角落之主 | N | 空间 | 四角方块参与合成时 ×2 |
| 边缘行者 | N | 空间 | 贴边合成 mult +2 |
| 大器晚成 | N | 大数 | 棋盘每有一个 ≥256 的方块，mult +1 |
| 双喜 | N | 通用 | 同回合合成 2 次 → 下回合 mult ×1.5 |
| 低语 | N | 低阶 | 每次合成出 2，该次合成 mult ×3（「Cavendish 位」：廉价但能定义整局） |
| 二五之数 | R | 低阶 | 2+2=5（合出 5，额外 +500 分），破坏 2 的幂结构 |
| 奇数炼金 | R | 低阶 | 所有合成结果 -1（4→3、8→7），制造奇数连锁 |
| 偶数净化 | R | 低阶 | 奇数方块合成时不升级，直接消除得分 |
| 空位之赐 | R | 空间 | 每个空格 mult +0.5（3×4 棋盘组合即起飞） |
| 弃子 | R | 通用 | 每关 2 次，移除任意 1 个方块（解死局神器） |
| 二五之数·对 | SR | 低阶 | 5+5=10 且再次触发二五之数效果（组合技） |
| 广阔天地 | SR | 空间 | 棋盘扩至 5×5，但目标分 ×1.2 |
| 大小通吃 | SR | 通用 | 合成时可选升级或降级方向（棋盘控制权质变） |
| 时间旅行 | SR | 通用 | 每关 1 次，撤销上一步（Boss 期价值翻倍） |

待设计的关键位：经济类附魔（金钱/+刷新降价）2–3 张、Boss 应对类 3–4 张（护盾/净化/反噬方向），MVP 内补齐。

## 6. Boss 系统（差异化主战场）

核心原则（小丑牌 Boss Blind 的直接移植，见 §12.4）：Boss 不做数值墙，而是**让玩家当前最强的套路失效**——每条规则针对一种流派，逼玩家备 Plan B。Boss 规则进关前公示，给玩家在商店构筑对策的窗口（对标 Boss Blind 开打前可见）。

**A 类 · 规则改写型**（对标 Balatro）：

| Boss | 规则改写 | 对标 |
|---|---|---|
| 偏见者 | 本关 4 和 8 不参与合并 | Debuff 花色（The Head 等） |
| 双合者 | 每回合必须完成 ≥2 次合并，否则该回合 0 分 | The Psychic（必须打满 5 张） |
| 老一套 | 不得连续两回合用同一滑动方向 | The Eye（牌型不得重复） |
| 降级者 | 每回合结算后，棋盘最高级 tile -1 | The Arm（牌型等级 -1） |
| 钝刃 | 本关基础分减半（+Mult/×Mult 不受影响） | The Flint |
| 独步 | 只能滑 15 步，但目标分降为 ×1 | The Needle（只能打 1 手） |
| 巨墙 | 目标分 ×4，无其他规则 | The Wall |

**B 类 · 棋盘干扰型**（2048 原生差异化，每 N 回合触发）：

| Boss | 干扰方式 | 克制的流派 |
|---|---|---|
| 塞数者 | 往随机空位塞一个 32 | 空间流 |
| 冻结师 | 冻结一行 2 回合（该行不可滑动） | 迫使改变滑动轴向 |
| 大窃贼 | 偷走棋盘上最大的方块 | 大数流克星；养多个中数可对冲 |
| 洗牌者 | 每 8 回合强制重排全盘 | 布局型附魔 |
| 心魔 | 合成分减半 3 回合 | 爆发型附魔在窗口期冲分 |

- Boss 出现在每章第 4 关；HP = 目标分，打满即击败。MVP 共 5 个 Boss（偏见者/双合者/塞数者/大窃贼/洗牌者），3 个 Boss 关各按「A 类抽 1 + B 类抽 1」叠加，章节越深越狠。
- **商店对策位**：Boss 关前一关的商店必出 1 张 Boss 应对类附魔/券（净化/护盾/「无效化 Boss 规则一次」），保证 Plan B 可达。
- 击败 Boss 掉 1 张 R+ 附魔（保底成长感）+ 大额金钱。

## 7. 经济与商店

- 金钱来源：① 通关基础奖励（普通关 $4 / Boss 关 $6，随章节递增）；② **剩余回合换钱**（每 2 回合 $1，上限 $5——把「效率」货币化，对应 Balatro 剩一手牌 $1）；③ **利息**（结算时每 $5 存款 +$1，上限 $5——鼓励攒钱择机消费）；④ 合出大数字的一次性奖金（首个 128/256/512…）。
- 商店（关卡间）：3 个附魔位 + 2 个功能位 + 刷新按钮。功能券池：清行券、换位券、**整形券**（棋盘上 3 个 2 变 4，或删 2 个最小方块——Tarot 牌库整形的映射）、**豪赌券**（销毁棋盘一半方块，随机换 1 张 R 级附魔——Spectral 高风险高回报的映射）。
- 刷新 $5 起，每 roll +$1 且**跨关累积、整局不重置**（Balatro 同款：第一关刷两次，第三关就要为前两次买单）——逼玩家做「买/刷/攒」的三选一，经济即构筑资源。

## 8. IAA 广告点（MVP 三个，必做）

| 广告点 | 时机 | 激励 |
|---|---|---|
| 复活 | 失败/死局结算前 | 清除全盘最小 8 个方块，续命一次 |
| 商店刷新 | 关卡间商店 | 本次刷新免费 |
| 分数×2 | 通关结算页 | 本关得分翻倍 → 影响金钱结算 |

原则：广告买的是「进度挽回」和「资源加速」，绝不卖影响构筑公平性的强度。

## 9. 明确暂缓（MVP 不做）

- 题材换皮（修仙皮）：等玩法核验证后再上，换皮是买量素材层面的放大器，不是玩法。
- 日挑战（固定 seed）+ 好友榜 + 分享裂变：上线标配，首发后第一个迭代补。
- PvP、成就系统、多角色/初始协议选择。

## 12. 小丑牌设计研究（调研输入）

完整研究笔记：[[Random/小丑牌设计研究]]（数值公式、Joker 配比、Boss Blind 规则库、经济系统、经典流派、成瘾性设计原理，全部带来源）。以下为已落入本 PRD 的迁移结论：

- 分数公式乘法化 + 三档附魔（+基数/+Mult/×Mult）+ 槽位顺序结算 → §5.0
- 目标曲线前陡后缓（×2.5→×1.5）+ 章内 1×/1.5×/2× → §4
- Boss = 规则改写而非数值墙，进关前公示 + 商店对策位 → §6
- 经济：剩步换钱 + 利息封顶 + reroll 跨关累积 → §7
- 整形券（Tarot）/豪赌券（Spectral）→ §7
- 稀有度≠强度，保留 Cavendish 式廉价强卡 → §5.3「低语」
