# esp-create

简介：这个项目是 esp 这个项目里面新建广告的入口，即微前端的其中一个组件，里面包含了比较复杂的依赖包，还有低代码运行时，还会涉及到大模型的另外一个仓库给作为微前端嵌入到这个项目当中


包的依赖图参考：
[[esp-create 包依赖图]]

其中:
- monorepo 来用一个 git 仓库管理所有包的版本，可以让每个包之前的依赖不在关心版本问题，在同一个 git 仓库引用即可

- turbo是用来解决各个包启动的时序问题，因为某些包作为依赖是必须先构建/启动完毕的，不然应用层的包会出现确实依赖的情况
- meta-tools他是一个工具集，在这个项目有几个作用：
	- 在组件库的包来定制一套组件构建的标准化流程
- pnpm 的 workspace 用来显式声明各个包之间的依赖关系
- create 包内部会用到 qiankun 之类的微前端框架，用于在多个场景，例如单独部署/作为一个子应用进行部署
- KMI 是快手内部的类似 Umi的 SPA 框架，管理路由/请求/监控埋点/初始化

```txt
packages/create        -> PC 应用
  依赖:
    @ad/create-biz
    @ad/create-mobile-biz
    @ad/create-component
    
    //上面是内部有，在 monorepo 里面的
    //而下面的这个表单包是在仓库中没有，在另外一个仓库的，用于表单验证
    @ad/ad-create-core ← 快手内部另一个仓库发布的
		表单引擎，提供 useModule/SchemaModule/FieldRender
		这是 biz 包和 create 包的"胶水层"
	@ad/create-runtime — 广告创编表单低代码运行时
	@ad/canal-react-runtime — Canal 大运河通用低代码运行时
	
packages/esp-mobile    -> Mobile 应用
  依赖:
    @ad/create-biz
    @ad/create-mobile-biz

packages/biz           -> PC/通用业务物料库
packages/biz-mobile    -> 移动端业务物料库
packages/component     -> 组件库
```
