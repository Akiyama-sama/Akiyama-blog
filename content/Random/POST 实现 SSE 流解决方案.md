在之前的[[揭榜挂帅比赛项目前端]]里面，需要用到携带请求参数的 SSE 请求，但原生 SSE API 当中是仅支持 GET 请求，因此只有自己实现 Fetch+ReadableStream 的方案，但这个方案的缺点在于：必须自己手写解析、断线重连、心跳、最后关闭等等逻辑，我考察一下有没有什么社区的解决方案


看了下[微软](https://github.com/Azure/fetch-event-source)的这个包可以实现一次 POST 请求然后接受一个 SSE 流连接，后续可以利用这个包来隐藏复杂度降低心智

然后后端会直接返回一个 JSON 格式的流，我需要和后端沟通各个 Event 事件类型，data 里面的类型约束好后才好进行行动，在之后 JSON 美化的实施后也可以实现利用这里的 SSE 连接来流式输出美化后的消息，因此在data 类型设计时需考虑到这种情况
