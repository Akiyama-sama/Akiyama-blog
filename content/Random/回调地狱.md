假设你要做三件事：
1. 登录用户
2. 获取用户信息
3. 保存日志
```js
loginUser("user", "password", function(user) {
  getUserInfo(user.id, function(info) {
    saveLog(info, function(result) {
      console.log("一切完成！");
    });
  });
});

```
这三件事情的函数分别作为上层函数的回调函数。当嵌套的层次多起来后，不好进行维护与开发
