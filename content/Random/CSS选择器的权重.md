[[!important]]>[[内联样式]]>id选择器>类/伪类选择器>元素/伪元素选择器>通配符

上面的规则也被称为[[四元组]]

| 选择器类型      | 示例                       | 权重值  |
| ---------- | ------------------------ | ---- |
| !important | `color: red !important;` | ∞    |
| 内联样式       | style="..."              | 1000 |
| ID 选择器     | #header                  | 100  |
| 类/属性/伪类    | .btn, [type], :hover     | 10   |
| 元素（标签）/伪元素 | div, ::before            | 1    |
| 通配符/继承样式   | *                        | 0    |
