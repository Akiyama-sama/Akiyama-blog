# NAPKIN | 餐巾纸

## 公式

```text
+----------------------------------------------------------+
|                                                          |
|   Loyalty ≈ 1 - (W / S)                                  |
|                                                          |
+----------------------------------------------------------+
```

忠诚度取决于“被替代的恐惧”：当核心支持者（W）在全体选民（S）中占比越小，他们被踢出分赃圈的风险越高，对现任领导人的忠诚度就越高。

## 一句话

政治生存不是关于“为民服务”，而是关于如何精准地通过分配资源来收买足够数量的核心支持者，以维持自己的权力。

## 草图

```text
    +-----------+
```

# ROUND 1: SKELETON | 骨架扫描

"这本书在说什么"

## 核心问题

为什么坏的政治行为（腐败、压迫、低效）往往是好的政治策略？

## 核心答案

领导人的唯一目标是政治生存，而生存取决于满足“获胜联盟”的需求，而非满足大众的需求。

## 章节骨架

1. 政治规则: 权力三维度与五大准则。
2. 上台之道: 寻找联盟的裂缝。
3. 掌权之术: 控制收入流，精准分配。
4. 窃取民财: 税收与资源的政治学。
5. 外部援助: 独裁者的救命稻草。
6. 灾难政治: 为什么苦难对统治者有利。
7. 变革之路: 如何通过结构调整实现民主。

## 论证结构

演绎型。基于“理性人”假设，通过选择集理论（Selectorate Theory）推导出不同政体下的领导人行为模式。

# ROUND 2: DISSECTION | 血肉解剖

"凭什么这么说"

## 论证链

```text
权力欲望 --> 识别获胜联盟(W) --> 控制收入 --> 优先支付W --> 维持忠诚 --> 政治生存
```

## 关键证据

1. **罗伯特·穆加贝 (津巴布韦)**: 通过恶性通货膨胀摧毁中产阶级（非核心盟友），同时用外汇支付军队（核心盟友）以维持统治。
2. **外国援助**: 数据显示，接受大量援助的独裁国家，其领导人寿命更长，因为援助提供了不依赖于国民税收的“自由现金流”。
3. **自然灾害**: 1970年波拉气旋后，巴基斯坦政府将救灾物资优先分发给政治盟友，导致东巴基斯坦（孟加拉国）因被忽视而独立。

## 隐形假设

- 领导人是纯粹的理性权力追求者，没有意识形态或道德约束。
- 政治生存是所有决策的最高优先级。

## 边界条件

- **破产**: 当收入流彻底枯竭，无法支付核心盟友时，统治会瞬间崩溃。
- **外部干预**: 强力外部军事干预可以打破内部的权力平衡。

# ROUND 3: SOUL | 灵魂提取

"还能怎么用"

## 作者盲点

忽略了意识形态、宗教和民族主义在动员群众和维持联盟中的非物质作用。

## 跨域映射

- 在 **公司治理** 中，CEO是领导人，董事会是获胜联盟（W），股东是名义选民（S）。
- 在 **创业团队** 中，早期核心员工是W，如果W过大，资源分配不均会导致团队分裂。

## 知识连接

- 与马基雅维利的《君主论》呼应，但提供了更现代的量化框架。
- 与阿西莫格鲁的《国家为什么会失败》互补：本书解释了“为什么领导人故意选择失败的制度”。

## 行动触发

- **制度设计**: 若要减少腐败，必须扩大获胜联盟（W）的规模，使领导人无法通过私人利益收买所有人，从而被迫提供公共产品。
- **反思援助**: 意识到无条件的国际援助往往是在延长独裁者的寿命，而非帮助灾民。
