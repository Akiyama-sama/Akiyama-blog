# 移动端适配

## 核心原则

> 移动端适配的本质是**内容优先、灵活响应**，而不是为每个设备单独写一套样式。

---

## 一、视口配置（第一步）

```html
<meta
  name="viewport"
  content="width=device-width, initial-scale=1.0, maximum-scale=1.0, user-scalable=no"
/>
```

| 属性                   | 作用          |
| -------------------- | ----------- |
| `width=device-width` | 视口宽度 = 设备宽度 |
| `initial-scale=1.0`  | 初始缩放比例 1:1  |
| `maximum-scale=1.0`  | 禁止用户放大（可选）  |
| `user-scalable=no`   | 禁止缩放（可选）    |

> [!warning] 注意
> 除非必要，否则不要禁止用户缩放，这会影响可访问性。

---

## 二、布局策略

### 1. 避免固定宽度，尽量使用相对单位

```css
/* ❌ 固定宽度 */
.container {
  width: 375px;
}

/* ✅ 相对宽度 */
.container {
  width: 100%;
  max-width: 600px;
}
.container {
  width: 90vw;
}
```

### 2. 弹性盒子（Flexbox）

```css
.container {
  display: flex;
  flex-wrap: wrap; /* 换行 */
  gap: 16px; /* 项目间距 */
}

.item {
  flex: 1 1 300px; /* flex-grow, flex-shrink, flex-basis */
  min-width: 0; /* 防止flex子项溢出 */
}
```

### 3. 网格布局（Grid）

```css
.container {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(300px, 1fr));
  gap: 16px;
}
```

---

## 三、尺寸单位

| 单位        | 说明           | 适用场景           |
| ----------- | -------------- | ------------------ |
| `%`         | 相对于父元素   | 宽度、间距         |
| `vw/vh`     | 相对于视口     | 整体布局、流式高度 |
| `rem`       | 相对于根字体   | 字体大小、间距     |
| `em`        | 相对于当前字体 | 元素内部相对缩放   |
| `vmin/vmax` | 视口短边/长边  | 响应式正方形       |

### rem 适配方案

```css
/* 假设设计稿 375px 宽度，根字体 16px */
/* 1rem = 16px */

/* 简单方案：js 动态设置 html font-size */
document.documentElement.style.fontSize = window.innerWidth / 37.5 + 'px';

/* 精细方案：配合 postcss-rem-to-responsive-pixel */
```

## 四、媒体查询（Media Queries）

### 断点策略

```css
/* 手机（默认样式） */
.container {
  padding: 16px;
}

/* 平板竖屏 */
@media (min-width: 768px) {
  .container {
    padding: 24px;
  }
}

/* 平板横屏 / 小笔记本 */
@media (min-width: 1024px) {
  .container {
    padding: 32px;
  }
}

/* 桌面显示器 */
@media (min-width: 1440px) {
  .container {
    padding: 48px;
    max-width: 1200px;
    margin: 0 auto;
  }
}
```

### 常见断点参考

| 设备  | 断点             |
| --- | -------------- |
| 手机  | < 768px        |
| 平板  | 768px - 1024px |
| 桌面  | > 1024px       |
| 大屏  | > 1440px       |

### 媒体查询类型

```css
/* 宽度 */
@media (min-width: 768px) {
}

/* 高度 */
@media (min-height: 600px) {
}

/* 像素比（Retina屏） */
@media (-webkit-min-device-pixel-ratio: 2), (min-resolution: 192dpi) {
  .logo {
    content: url(logo@2x.png);
  }
}

/* 横竖屏 */
@media (orientation: landscape) {
}
@media (orientation: portrait) {
}

/* 混合条件 */
@media (min-width: 768px) and (max-width: 1024px) {
}
```

## 五、图片适配

```css
/* 响应式图片 */
img {
  max-width: 100%;
  height: auto;
  display: block;
}

/* art direction - 不同设备显示不同图片 */
<picture>
  <source media="(min-width: 1024px)" srcset="large.jpg">
  <source media="(min-width: 768px)" srcset="medium.jpg">
  <img src="small.jpg" alt="描述">
</picture>
```

## 六、移动端特性

### 1. 点击高亮（tap highlight）

```css
* {
  -webkit-tap-highlight-color: transparent;
}
```

### 2. 字体抗锯齿

```css
body {
  -webkit-font-smoothing: antialiased;
  -moz-osx-font-smoothing: grayscale;
}
```

### 3. 触摸区域

```css
/* 增大触摸目标 */
button,
a {
  min-height: 44px;
  min-width: 44px;
  padding: 12px;
}
```

### 4. 固定定位兼容

```css
/* 移动端 fixed 定位问题 */
.footer {
  position: fixed;
  bottom: 0;
  left: 0;
  right: 0;
  /* 某些浏览器需要设置 z-index */
  z-index: 9999;

  /* 安全区域适配（iPhone X+） */
  padding-bottom: env(safe-area-inset-bottom);
  padding-bottom: constant(safe-area-inset-bottom);
}
```

## 八、常见问题

> [!warning] 常见坑点

1. **1px 边框在高清屏模糊**

   ```css
   /* 使用 transform 缩放或 box-shadow */
   .border {
     box-shadow: 0 0 0 1px #ddd;
   }
   ```

2. **300ms 点击延迟**

   ```css
   /* 解决方案1：禁用缩放（已在viewport设置） */
   /* 解决方案2：使用 CSS */
   * {
     touch-action: manipulation;
   }
   ```

3. **输入框聚焦页面缩放**

   ```html
   <meta name="viewport" content="width=device-width, initial-scale=1.0" />
   <!-- iOS 需要在 CSS 中设置 font-size >= 16px -->
   input { font-size: 16px; }
   ```

4. **100vh 包含地址栏**

   ```css
   /* 使用动态视口单位或 JS 计算 */
   .full-height {
     height: 100vh;
   }
   /* 或 */
   .full-height {
     height: 100dvh;
   } /* 动态视口高度 */
   ```

5. **fixed 元素在 iOS 滚动穿透**
   ```css
   body {
     position: fixed;
     overflow: hidden;
   }
   /* 或使用 overflow: auto 但配合 -webkit-overflow-scrolling */
   ```

## 总结

| 策略                  | 优先级       |
| --------------- | --------- |
| 视口配置              | ⭐⭐⭐ 必须第一步 |
| 弹性布局（Flex/Grid） | ⭐⭐⭐ 核心    |
| 相对单位              | ⭐⭐⭐ 基础    |
| 媒体查询              | ⭐⭐ 响应式点   |
| 图片适配              | ⭐⭐ 高清屏    |
| 移动端特性            | ⭐ 优化体验    |

> 一句话：**用百分比/弹性盒子弹性布局，用媒体查询处理极端情况，用 rem/vw 做整体缩放**。
