# 2025最新React技术栈 后台管理系统模板
想必大家已经找过很多后台管理的开源项目，但UI不尽如人意，今天我要向大家介绍的是我最近开源的[后台管理系统模板](https://github.com/Akiyama-sama/backend-admin-template)

backend-admin-template是用React19+TypeScript开发，React Router进行路由管理，并用Zustand和JWT进行权限管理与鉴权，UI方面采用的是[ShadcnUI](https://ui.shadcn.com/)+[Tailwind CSS](https://www.tailwindcss.cn/docs/installation)，您可以根据ShadcnUI官网安装，并进行自定义组件，在CRUD方面用的是Tanstack Table，这个包专门对表格进行了优化，让表格数据进行按需加载，增加渲染速度。
