# JD
【任职要求】
有 AI 原生游戏/AI角色扮演类产品开发项目或实习经验优先。对AI原生应用开发有浓厚兴趣，有构建AI原生应用的项目或实习经验者优先。优秀者薪资可谈。 本科及以上学历，计算机科学或相关专业，前端或全栈开发经验。 精通 React 及其技术生态（如 Redux/MobX, React Router, Next.js 等），具备扎实的 JavaScript/TypeScript 基础和良好的代码规范。 熟悉前端工程化工具（如 Webpack, Vite, Babel），对组件化开发、前端性能优化、浏览器渲染原理有深入理解和实践经验。 具备优秀的前端架构设计能力，能独立负责前端模块的设计与开发。 积极主动，具备快速学习能力和出色的问题解决能力，能在高不确定性的创业环境中高效工作。 
【岗位职责】 核心产品功能开发： 负责产品核心功能的前端开发，与产品经理、设计师和后端工程师紧密协作，确保高质量的用户体验和界面实现。 前端架构设计与实现： 参与设计和构建稳定、可扩展、高性能的前端应用架构，实现复杂的AI驱动的用户交互逻辑。 交互体验实现： 将设计和原型转化为功能完善、响应迅速的前端界面，对标行业顶尖产品的交互体验。 技术攻坚与性能优化： 解决前端在复杂交互、AI原生内容动态生成与展示等场景下的技术挑战，持续优化前端性能、加载速度和用户体验。
