mcp 是一套通用协议，允许开发者通过通用接口，将 ai 工具连接到各个工具/数据源当中

mcp协议 主要解决的是模型调用工具的接口适配问题，避免为各大厂商的模型调用工具时写适配器


而 mcp 服务器是满足了 mcp 协议的一个后端服务，能够让大模型能够像调用 REST 服务器的接口那样调用“接口”

与[[skill]]不同的是，skill 虽然能够通过渐进式披露提示词，教会大模型直接通过 cli 来调用工具，但大多本地运行的这类工具十分轻量，直接能够通过 bash 或者脚本直接运行，而类似高德地图之类的大型后端服务是不可能在本机并通过 cli 来调用的
