在前端工作过程当中，除了编写代码以外，还有一项看似不相关，但又不得不做，甚至是这个时代差异化竞争的必选项：UI/UX

UI/UX 包含很大一块内容，不仅对你的审美有要求，还需要学习相应的设计语言，我自己确实是需要系统性学习这方面的内容才能真正的做出更美观，更有创造力的 UI/UX

但对这方面无经验的我来说，急需找到一种替代方案，能让我在不接触 UI/UX的情况下，让 AGENT 能自己做出视觉一致性，UI一致性的画面：

# 方案

1. 采用 UI 一致的组件库，方便利用 css 变量来对里面的配色、字体、间距、圆角角度进行配置化操作，典型案例就是 shadcn UI，我用这个组件库做过[[揭榜挂帅比赛项目前端]]、以及[[杭州深维智元科技 前端实习生]]里面的项目，然后利用[tweak](https://tweakcn.com/)来对里面的配色等等进行手动调整
2. 参照各家[DESIGN.md](https://github.com/VoltAgent/awesome-design-md?tab=readme-ov-file)里面的内容，刚给出的链接都是遵循[google stitch](https://stitch.withgoogle.com/docs/design-md/format)的 DESIGN.md格式的各家大厂落地页面的设计语言，让 AGENT 阅读这个 md 后直接进行修改为 html，但这里有一个问题：即当一个 html 文件达到 2000 多行的时候，此时注意力就会被稀释，导致改进效果变差，因此既然都开始 vibe coding 了，为何不直接采取注意力稀释最低的方式：React+Tailwind 来构造一个纯前端原型呢？


# 闲言碎语

在进行对UI/UX 设计而烦恼时，突然想起之前看到的一个 mc 建筑的一个视频，里面介绍了一些美的规范化表达，我仔细搜索了过后，这样的规范化表达有一个专有名词：[[形式美法则]]，这个名词用于指导人们如何以一种能够语言形式化、规范化的方式来构造美，发现美
