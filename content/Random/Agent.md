Agent 是一个具备：

感知-规划-行动-记忆 的能力，自主达到复杂目标的一个智能主体

Agent 是“工具”与“主体”的对立统一。作为工具，它顺从人类指令；作为主体，它在黑盒内部生成人类不可预测的中间步骤。更高层级的统一在于：它是人类意志的延伸，而非单纯的替代。
