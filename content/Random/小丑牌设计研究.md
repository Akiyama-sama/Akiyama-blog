# 小丑牌设计研究

> 网络调研（Wiki/攻略站/GDC 演讲报道/Reddit），关键数据有交叉来源。结论已回填 [[Project/肉鸽 2048|肉鸽 2048 PRD]] 的 §4 曲线 / §5 附魔 / §6 Boss / §7 经济。

## 1. 核心数值公式

- **得分 = Chips × Mult**。牌型给基础值（高牌 5/1、顺子 30/4、同花 35/4、四条 60/7），打出的牌加 chips（2–10 按面值，JQK=10，A=11），Joker 插入 +Chips、+Mult、×Mult 修改器。
- **结算管线从左到右**：每张牌结算时逐个触发 Joker——Joker 摆放顺序本身是构筑资源（先 +Mult 后 ×Mult，被乘基数才大）。
- 为什么乘法爽：+Chips/+Mult 线性，×Mult 把曲线指数化；「大数 × 大数 = 天文数字」是官方设计思路（[GDC 2025 演讲报道](https://gamedeveloper.com/design/chips-and-multipliers-the-addictive-alchemy-of-balatro)）。
- **Blind 目标曲线（ante 1–8 小盲）**：300 / 800 / 2000 / 5000 / 11000 / 20000 / 35000 / 50000；大盲 = 1.5×，Boss = 2×（[Blinds and Antes Wiki](https://balatrogame.fandom.com/wiki/Blinds_and_Antes)）。**增长前陡后缓**：ante 1→4 约 ×2.5/级，5→8 放缓到 ×1.4–1.8；恒定 ×1.6 只在无尽模式 ante 39 起出现（社区实测 1.605）。

## 2. Joker 设计

- 150 张 = Common 61（刷出率 70%）/ Uncommon 64（25%）/ Rare 20（5%）/ Legendary 5（0.3%，商店不出，只能从 Spectral 牌 Soul 获得）。商店基准价 $4/$6/$8/$20。
- **稀有度 ≠ 强度是刻意设计**：$4 的 Common 卡 Cavendish（×3 Mult，1/1000 自毁）能 carry 整局。
- **触发条件是设计主轴**：when scored / held in hand / on discard / independent，再叠加卡片区、牌型、花色条件，构成组合空间。
- **Legendary 的语言是「改写规则」而非「给大数字」**：Chicot 无效化一切 Boss 规则；Yorick 弃满 23 张后 ×5；Perkeo 给消耗品做免槽位复制。

## 3. 周边系统

- **Tarot（$3–5，改牌）**：编辑牌池本身——销毁杂牌压缩牌库提高摸中率、同化牌凑同 rank；牌库整形是隐形构筑轴。
- **Planet（升级牌型）**：13 星球对应 13 牌型，每级永久 +chips/+mult，不占槽位、收益永续，白赚必拿。
- **Spectral（高风险高回报）**：常带销毁代价——复制随机 Joker 但毁原件、×2 Mult 但清空卖价。
- **Voucher（$10，全局成长）**：买的是「整局经济函数」——利息上限 $5→$10/$20、reroll 曲线改写、全店 75 折。
- **跳小盲拿 Tag 的 risk-reward**：跳过小盲=放弃其金钱，好 Tag 值得赌，Double Tag 可翻倍。

## 4. Boss Blind 规则库（28 个，采样）

Boss 不直接伤害，而是**让玩家最强的动作失效**。五类：封牌型 / 改手牌 / 改牌库 / 改资源 / 改分数。

| Boss                      | 规则改写                  |
| ------------------------- | --------------------- |
| The Wall                  | 目标分数 ×4（普通 Boss 是 ×2） |
| The Needle                | 只能打 1 手，但目标只要 1×      |
| The Psychic               | 每手必须打满 5 张            |
| The Eye                   | 本回合牌型不得重复             |
| The Mouth                 | 本回合只能打一种牌型            |
| The Arm                   | 打完后所打牌型等级 -1          |
| The Flint                 | 牌型基础 chips/mult 减半    |
| The Hook                  | 每打一手随机弃掉 2 张手牌        |
| The Fish                  | 之后摸的牌面朝下（不可见）         |
| The Water                 | 开局 0 次弃牌              |
| The Manacle               | 手牌上限 -1               |
| The Ox                    | 打出本局最常用牌型 → 金钱清零      |
| The Tooth                 | 每打出一张牌 -$1            |
| The Club/Goad/Window/Head | Debuff 某一整花色          |
| The Plant                 | 所有 JQK 被 debuff       |

Showdown 层更狠：Violet Vessel 目标 ×6、Verdant Leaf 全场 debuff 直到卖掉一个 Joker（**逼你拆自己的构筑**）、Crimson Heart 每手随机禁用一个 Joker。设计共性：每条规则针对一种「获胜策略」，逼玩家备 Plan B 或用道具反制（Luchador/Chicot 可无效化 Boss）。

## 5. 经济系统

- 收入：小盲 $3 / 大盲 $4 / Boss $5 + 每剩一手 $1 + 每剩一次弃牌 $1 + 利息 $1/$5（上限 $5）。「效率」被货币化，赢太快也有奖。
- **Reroll $5 起每 roll +$1，跨关累积不重置**——第一关刷两次，第三关就要买单。存钱是策略（利息+择机），花光是常态压力。

## 6. 经典流派

- **Baron + Mime**：手中每张 K ×1.5，Mime 重触发 held-in-hand 效果 → 每个 K 吃两次，无尽模式天花板引擎。
- **Flush Five**：DNA 复制 + Tarot 整形凑五同花五同，基础 120×12。
- **血脉流**：红桃 1/2 概率 ×3 Mult + 花色同化 + 重触发，赌随机性的 mult 堆叠。
- **Perkeo 负面流**：消耗品无限免槽复制，成长率翻倍。
- 通用骨架：前期打钱过渡 → 中期找 ×Mult 核心 → 后期全槽位服务单一引擎。**构筑成型时刻即爽点峰值**。

## 7. 成瘾性设计原理

1. **指数目标 vs 自选指数**：目标每 ante ×1.5–2.5，玩家的 ×Mult 构筑是自选底数的指数——一场「构筑能否跑赢曲线」的军备竞赛。
2. **难度从不宣告，失败责任内化**：曲线藏在平滑呈现后面，输局被归因于自己的构筑错误而非设计恶意，悔恨驱动「再来一局」。
3. **变比率强化 + 近失效应**：差 0.1% 没打过 Boss 是下一次开局的最强燃料（老虎机心理）。
4. **算术被 Juice 化**：数字抖动、逐个结算、震屏音效把纯乘法做成拉老虎机的感官体验。
5. **允许破坏、禁止通杀**：故意不平衡让玩家当一次天才，但曲线陡到无法摧毁挑战——构筑成型 ≠ 游戏结束。

## 8. 可迁移到肉鸽 2048 的设计启示

- 分数公式乘法化 + 三档附魔（+基数/+Mult/×Mult）+ 槽位顺序结算
- 目标曲线前陡后缓（×2.5→×1.5）+ 章内 1×/1.5×/2×
- Boss = 规则改写而非数值墙，进关前公示 + 商店对策位
- 经济：剩步换钱 + 利息封顶 + reroll 跨关累积
- 整形券（Tarot）/豪赌券（Spectral）/买断式全局升级（Voucher，暂缓）
- 稀有度≠强度，保留 Cavendish 式廉价强卡
