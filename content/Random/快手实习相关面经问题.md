## 面经相关问题

Schema 驱动表单的联动逻辑实现
Schema 底层是自己封装的，还是用了开源的？  
面对复杂场景的联动（如省份和市级联动，或自定义表单项联动），是如何解决的？  
当用户修改表单中的一个字段时，它的更新范围是什么？全量还是局部？  

罚单低代码平台大概节约了多少运营人力？运营的人工成本有统计过吗？
讲一下实习中的自主研发 MCP  
在你的认知里面，MCP 跟传统 API 有什么区别？  
MCP 之前是怎么实现和 AI 调用外部工具的？了解吗？  
这边有个指标要显著降低：产研沟通与代码维护成本。有具体的数据吗？（面试官非常在意数据的值）  
除了接需求，有需求过来我就做，有没有去思考过，现在做的一些东西的价值是什么？为什么要做这些？  
快手那边有沉淀一些 workflow 相关的东西吗？  
之前公司已经有大量基建设施，现在离开了，你怎么把那些好用的东西沉淀下来给自己用？


## 如何准备这些问题

今天在2026-07-06，离秋招还有一段时间，得准备好如何回答这些问题

- 低码相关，得理清楚整条数据链路以及相关细节
- 数据相关，例如做的这些有带来什么相关收益这些，收益写上的数据是怎么来的，得说清楚
- 业务价值相关，得自己捋清楚做这些业务需求的背景、目标、方式、收益是什么
- 个人沉淀相关，例如这次实习沉淀下来的有哪些东西
