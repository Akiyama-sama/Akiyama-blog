# IAA 小游戏品类与爆款母题

> [!info] 结论先行
> IAA 的流量集中在**消除、物理解压、脑洞解谜、模拟经营、IO 大作战**这几类轻量玩法上。爆款母题(倒水、拧螺丝、挪车、画线)全部满足同一公式:**零学习成本 + 单局十几秒 + 解压/脑洞情绪钩子 + 难度卡点逼出"看广告续命"**。2026 上半年 IAA 百强前三:《羊了个羊:星球》《抓大鹅》《打个螺丝》。相关:[[Random/IAA 与 IAP 的区别]]、[[Random/微信小游戏生态与题材调研]]。

## 一、IAA 大盘(2025-2026)

- 微信小游戏 IAA 规模同比 **+20%**,占国内 IAA 大盘 **40%**;IAA 用户 6.9 亿
- 官方公开课数据:**IAA 休闲品类指数增长翻倍**——休闲是 IAA 最强增长引擎;玩法融合类 IAA 同比 +27%
- 900+ 款 IAA 小游戏年流水破百万;**八成开发者为 30 人以内小团队**——这是中小团队的主场
- 头部集中度在下降:首发产品第三个月留存率从 15% 升至 18%,尾部产品机会变多
- 微信对新 IAA 游戏有「蓄力计划」:首月广告收入阶梯奖励最高 15 万元

## 二、流量大的品类 + 代表游戏

### 1. 消除 / 三消变体(IAA 第一大赛道)

- **《羊了个羊》**:原型是《3 Tiles》三消,第一关"幼儿园级"、第二关通关率宣传不到 0.1%,靠"卡关 → 看广告/分享拿道具"的高强度广告链路 + 省份排行榜社交裂变,一天 8 个微博热搜。《羊了个羊:星球》至今仍是消除赛道细分赢家
- **《抓大鹅》**:2026 上半年 IAA 百强第二,类似变体消除
- **满天果 like、沙画 like**:2026 上半年新跑出来的消除微创新,澎湃评价"消除+创新融合是中小团队最稳妥的立项方向"

### 2. 排序 / 倒水(物理解压常青树)

- **《脑力倒水》**(广州弈米)、**《倒水挑战》**(杭州同趣,全周期在榜、最高冲到百强第 4)
- 国际原型《Water Sort Puzzle》全球下载约 1.8 亿;同色液体归并试管,零门槛 + 强解压
- 变现卡点:看广告加管、撤销、提示

### 3. 拧螺丝(话题营销典范)

- **《打个螺丝》**:2024 年爆款延续到 2026 上半年百强第三,已迭代到 1.5 代~4 代;"别笑,你笑你也过不了第二关"式话题出圈
- **《无敌螺丝王》《拆螺丝》**:限时关卡 + 物理模拟 + 魔性音效
- 行业结论:**IAA 产品"话题大于玩法"**——玩法不新鲜,但社交平台话题发酵带来持续免费流量

### 4. 挪车 / 停车场(解谜母题)

- **《挪了个车》**(重庆云威):经典"拥挤停车场"滑块解谜,规则一句话说清,冲上抖音畅销榜 #93
- 打法:在抖音端复用微信端已验证玩法;靠关卡卡点的激励视频(提示/撤销/跳关)变现
- 风险:关卡是纯消耗品,关卡库见底即留存崩塌,抄袭门槛低

### 5. 钓鱼(休闲皮、养成芯)

- **《楚新钓》**:抖音/微信双端 rank 39;表面解压钓鱼模拟,内核英雄抽卡 + 装备强化 + 鱼塘放置,IAA/IAP 混变
- "甩竿爆钓大鱼"的爽感画面天然适合短视频传播

### 6. 画线救人 / 拉针救援(脑洞+物理)

- **《画线火柴人》**:抖音话题播放超 22 亿次;一笔画线护住火柴人,单局十几秒,易出搞笑反转片段
- **《脑洞画线我最强》**(抖音)、**《解救女孩》**
- **《Super Daddy》/ Pull the Pin 系**:按顺序拔插销,水灭岩浆、重物砸敌人
- 这类是"救援 + 物理判断 + 失败搞笑"三合一,素材钩子极强

### 7. 橡皮擦 / 擦除

- **《橡皮擦小姐姐》《脑洞求生小姐姐》**:擦掉画面关键部位解谜救人,擦错有危险,脑洞 + 诙谐剧情驱动;常与画线、推理混合成复合玩法

### 8. 清理 / ASMR 解压

- **《最强益智解压》**:点击拖拽清污渍,ASMR 音效 + 粒子反馈;解压素材"前后反差十秒讲完",是最好投的广告钩子

### 9. 合成(Merge)

- **《合成大西瓜》**:现象级国民合成(火到美国)、**《2048》**、海外 **《Merge Mansion》**合成+解谜经营融合
- "同类两两合并升级"短反馈解压,"合成+"在海外收入榜持续强势

### 10. 答题 / 文字

- **《成语小秀才》**:成语填空 + 官职晋升轻剧情;海外 **《Word Link》《Word Connect》**至少 50% 收入来自广告
- 题库闯关类对个人开发者友好:内容生产 > 技术难度

### 11. IO 大作战

- **《贪吃蛇大作战》《球球大作战》《黑洞大作战》(Hole.io)**;海外鼻祖 Agar.io / Slither.io
- "多人在线 + 简单操作 + 即时成长",单局 3 分钟,"吃与被吃"紧张感,天然适合碎片化社交

### 12. 模拟经营 / 放置

- **《动物餐厅》《小森生活》**(治愈系放置经营)、**《我是大东家》**(古风经商);海外标杆 Township / Hay Day
- 放置 Idle:**《全民漂移》《飞机大亨》**;超休闲物理:**《球跳塔》(Stack Ball)**
- 女性向模拟经营(《我的花园世界》《浪漫餐厅》)偏 IAP/混变,纯 IAA 端以放置经营为主

## 三、爆款公式的共性

1. **零学习成本**:规则一句话讲清(倒水=同色归并、挪车=按序开出、拧螺丝=拧完即走)
2. **单局极短**:十几秒到 3 分钟,碎片化即点即玩
3. **情绪钩子**:解压(倒水/清理/拧螺丝)、脑洞(擦除/画线)、挫败反差(羊了个羊)
4. **难度卡点逼广告**:道具稀缺,卡关处"看广告获得提示/撤销/复活/加管"——广告点位就是玩法的一部分
5. **社交/话题放大**:省份排行、UGC 梗传播("你笑你也过不了第二关")、短视频钩子素材
6. **素材测不过,代码一行不写**:IAA 爆款的本质是"钩子素材 × 核心循环"的极致咬合,不是画质

## 四、给个人开发者的落点

- **最稳妥**:消除微创新(满天果/沙画 like 方向)、物理解压(倒水/拧螺丝变体)——2026 上半年验证过的赛道
- **题材即素材**:选天然带"前后反差/搞笑反转/爽感画面"的母题,广告素材和 UGC 才有传播力
- **关卡型母题(挪车/倒水)要注意内容消耗**:要么留关卡生成方案,要么选玩法无限型(物理/合成/IO)
- **长线思维**:打螺丝迭代到 4 代还在榜——单一母题持续微迭代 > 频繁换题材;爆款 IAA 目标周期已从几个月拉长到 3 年+
- 微信「蓄力计划」首月最高 15 万奖励,新游冷启动先吃官方扶持
