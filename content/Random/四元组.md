我们将权重表示为 `(Inline, ID, Class, Element)`：
- **A (行内样式):** 如果是通过 HTML `style="..."` 属性定义的样式，则 A=1。 _(权重: 1, 0, 0, 0)_

- **B (ID 选择器):** 计算选择器中 **ID 选择器**（如 `#header`）的个数。 _(权重: 0, 1, 0, 0)_
- **C (类、属性、伪类):** 计算选择器中 **类选择器**（`.btn`）、**属性选择器**（`[type="text"]`）和 **伪类**（`:hover`, `:nth-child`）的总个数。 _(权重: 0, 0, 1, 0)_
- **D (标签、伪元素):** 计算选择器中 **标签名**（`div`, `span`）和 **伪元素**（`::before`, `::after`）的总个数。 _(权重: 0, 0, 0, 1)_
