Sass全称为 [Sass (Syntactically Awesome StyleSheets)](http://sass-lang.com/documentation/file.SASS_REFERENCE.html)，是一款强化 CSS 的辅助工具，扩展了CSS的语法

## 特性

- 完全兼容 CSS3
- 在 CSS 基础上增加变量、嵌套 (nesting)、混合 (mixins) 等功能
- 通过[函数](http://sass-lang.com/docs/yardoc/Sass/Script/Functions.html)进行颜色值与属性值的运算
- 提供[控制指令 (control directives)](https://www.sass.hk/docs/#t8)等高级功能
- 自定义输出格式

他有两种语法格式，一种是[[Scss]](Sassy CSS)，另外一种是Sass(Indented Sass) 通常简称 "Sass"
