(Sassy CSS)

支持css原生写法，在css基础之上添加了嵌套写法，由: {}组成

```scss
.container {
  width: 80%;
  margin: 0 auto;
  padding: 20px;

  .header {
    background-color: $primary-color;
    color: white;
    padding: 10px;
  }

  .content {
    margin-top: 20px;
  }
}
```
