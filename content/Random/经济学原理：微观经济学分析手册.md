# 经济学十大原理

## 人们如何做出决策

1. 权衡取舍：人们做出决策之前的一种净收益计算：即 Max(做出决策的收益-做出决策的成本，不做出决策的，而做其他事情的收益-做其他事的成本)

2. 某种东西的成本包括为了得到它所放弃的东西：某种东西的成本不仅仅是直接的，表观的，还可能是间接的，抽象的（例如说机会成本）。任何一种行为的成本可以用其所放弃的机会来衡量。
3. [[理性人]]考虑边际量：权衡成本并不是非黑即白的，存在一些“灰色地带”，在实际生产过程当中，会考虑增加一单位的带来的收益 - 增加一单位带来的成本。即边际收益 - 边际成本来做出决策，这里的边际收益以及边际成本可以统称为[[边际变动]]。
4. 人们会对激励做出反应：激励是引起一个人做出某种行为的一种事件。因为激励，会让理性人做出某种决策，因此在做出某种影响范围非常大的某种激励时，需要考虑到因为这个激励而带来的直接，或者间接的由理性人为此做出的反应。

## 人们如何做出影响

5. 贸易可以使每个人的状况都变得更好：贸易可以让各个人从事自己擅长的活动，并通过贸易来交换所需物品。因为专注从事擅长的活动，因此每个人的生产单一物品的[[生产率]]提高，总的生产率也提高，让每个人的状况都变得更好
6. 市场通常是组织经济活动的一种好方法：相比于中央计划经济，市场更能调控，反应一个物品在社会中的真实价值以及不会扭曲各个理性人的决策
7. 政府有时可以改善市场结果：市场需要政府来制定法律法规以及相关产权，以充分发挥看不见的大手的作用
## 整体经济如何运行

8. 一国的生活水平取决于他生产物品与服务的能力：及[[生产率]]为一国生活水平的主要因素
9. 政府发行过多货币，物价上升：发行过度货币引起通货膨胀，物价上升。
10. 通货膨胀与失业率呈负相关：通货膨胀物价上升，企业能获取更多利润，鼓励企业雇更多工人来生产商品，失业率下降。政府需要在这两者之间进行取舍权衡


# 科学的研究经济学

## 两种简化经济学模型

1. 循环流量图：经济简化为只有两类决策者的模型 - 企业以及家庭。企业购买并利用[[生产要素]]来生产服务以及商品，家庭拥有[[生产要素]]并消费
2. 生产可能性边界：他是一个 n 维图像，有着一条边界，边界上的点代表这生产 n 种商品的最大比例容量，在边界内部，说明这个国家还没有发挥出来他自己生产的最大潜力。并且边界是可以随时变化的，例如说某种商品因为技术等等因素，在相同的成本下可以生产更多，这样边界也会发生变化

## 科学家/顾问

经济学家通常会担任两种角色，主要是看他们的说辞是属于哪一种，就代表他们处于哪种角色当中：

1. 实证表述：做出这个世界是什么样子的表述，例如最低工资法引起了失业，此时担任的是科学家的角色
2. 规范表述：做出关于世界应该是什么样子的表述，例如政府应该提高最低工资，此时担任的是顾问的角色


# 比较优势原理

在说比较优势之前得说说[[绝对优势]]：在生产某项物品时，一个生产者比另外一个生产者的投入成本更低，就叫做绝对优势。

|       | 生产1盎司所需要的时间(分钟) |     | 8个小时的产量(盎司) |     |
| ----- | --------------- | --- | ----------- | --- |
|       | 牛肉              | 土豆  | 牛肉          | 土豆  |
| Frank | 60              | 15  | 8           | 32  |
| Rose  | 20              | 24  | 24          | 48  |


在上面的表格中，frank相较于rose在生产牛肉上有绝对优势，rose在生产土豆上相较于frank有绝对优势。

但经济学十大原理中的第二条原理是：某种东西的成本包括为了得到它所放弃的东西

|       | 1蛊司牛肉的机会成本 | 1盎司土豆的机会成本 |
| ----- | ---------- | ---------- |
| Frank | 4盘司土豆      | 1/4 盘司牛肉   |
| Rose  | 2蛊司土豆      | 1/2 盘司牛肉   |

在上面的表格中就计算出了各自生产以盎斯的牛肉或者是土豆，他们所隐藏的机会成本。例如，frank在生产伊盎司牛肉的时候，他可以生产四盎司土豆，但rose仅生产2盎司土豆，rose的机会成本比frank的机会成本小。因此，让rose生产牛肉更有效率。与上面的相同，frank 生产土豆的成本更低，应该由frank 来进行生产。

他们可以从事自己生产率更高的项目，并进行贸易。这样frank与rose，能得到他们原本自己生产来还要多的产品。

| **类别**     | **Frank (牛肉)** | **Frank (土豆)** | **Rose (牛肉)** | **Rose (土豆)** |
| ---------- | -------------- | -------------- | ------------- | ------------- |
| **没有贸易：**  |                |                |               |               |
| 生产与消费      | 4              | 16             | 12            | 24            |
| **有贸易：**   |                |                |               |               |
| 生产         | 0              | 32             | 18            | 12            |
| 贸易         | 得到 5           | 给出 15          | 给出 5          | 得到 15         |
| 消费         | 5              | 17             | 13            | 27            |
| **贸易的好处：** |                |                |               |               |
| 消费增加       | + 1            | + 1            | + 1           | + 3           |
|            |                |                |               |               |



所以，这里的[[比较优势]]就是指的各自生产某样产品的机会成本更低，在各个国家的贸易当中，都一般会出口，相较于其他国家有比较优势的产品，而进口没有比较优势的产品。


# 供给与需求

市场作为由某种物品或服务的买者与卖者组成的群体。买者作为一个群体，决定了一种产品的需求，而卖者作为一个群体，决定了一种产品的供给。

## 需求

需求量：买者愿意并且能够购买商品的数量
需求定理：其他条件保持不变，价格上升，需求量下降
需求表以及需求曲线：用于描述需求量与价格之间的关系，曲线就用函数来表示

需求分为市场需求以及个人需求，市场需求是每个人的个人需求总和

低挡物品：在其他条件相同时，引起收入与需求呈负相关的物品，例如收入下降后有更多人去乘坐公共交通

替代品：一种物品价格上升引起另一种物品需求量增加的两种物品，例如热狗价格上升，但汉堡能满足类似的愿望，而导致汉堡的==需求量==增加，就称热狗与汉堡为替代品

互补品：一种物品价格上升引起另一种物品需求量下降的两种物品，例如电脑的价格上升，导致用电脑的人变少，软件的使用人数也变少，就说电脑与软件为互补品

导致需求曲线变化的变量：价格、收入、相关物品价格、爱好、预期、买者数量
## 供给
供给量：卖者愿意并且能够卖出商品的数量
供给定理：价格上升，供给量增加
供给表与供给曲线：反应价格与供给量的关系
市场供给及个人供给的总和


## 供给与需求的结合

均衡：供给曲线与需求曲线的交叉点
均衡价格：交叉点的价格
均衡数量：交叉点的数量，即供给量或者需求量

过剩：价格高于均衡价格，导致供给量大于需求量
短缺：价格低于均衡价格，导致需求量大于供给量

供求定理：任何一种物品的价格会自发调整，使该物品的供给与需求达到平衡


**分析均衡变动的三个步骤**

1. 确定该事件是让需求曲线移动，还是让供给曲线移动还是都移动
2. 确定这个曲线的移动方向
3. 利用供求图来说明这些移动是如何改变均衡价格以及均衡数量的

# 需求弹性

[[需求价格弹性]]：之前都是定性的说明需求曲线往哪个反向走，但走多少还没有说清楚，这里的需求价格弹性就是用来衡量需求量对价格变动的反应程度，如果需求量对价格的反应很大，就说是**富有弹性的**，如果反应不大，就说是**缺乏弹性的**

有关需求价格弹性的经验：
- 相似替代品和可获得性：如果替代品很多，那么一般是富有弹性的，因为消费者可以选择哪个来进行消费。而替代品不多，一般都缺乏弹性，例如鸡蛋没有替代品，就是缺乏弹性的
- 必需品与奢饰品：必需品是缺乏弹性的，奢饰品是富有弹性的
- 市场的定义：狭窄的市场比宽泛的市场更富有弹性，例如食品这个宽泛的市场无替代品。而冰淇淋这个狭窄的市场有替代品：香草冰淇淋，因此其更富有弹性
- 时间范围：更长期更富有弹性

## 计算需求价格弹性

$$需求价格弹性 = \frac{需求变动量}{价格变动百分比}$$
而这里的价格变动百分比，因为从右到左计算还是从左到右计算的基数都不统一，因此计算出来的价格变动百分比不同，因此利用中点法来计算价格变动百分比，例如
A点：价格=4美元，数量=120
B点：价格=6美元,数量=80

中位数为 5，计算价格变动百分比：
$$\frac{6-4}{5}=0,4$$
各种需求曲线的弹性程度通过以下标准来进行判断：
- 需求价格弹性大于一，即富有弹性
- 小于一，缺乏弹性
- 等于一，具有**单位弹性**


**总收益与需求价格弹性的联系**

总收益 = 需求数量 * 价格

而因为需求价格弹性的不同，其曲线的变动而呈现出来的总收益不同

例如在富有弹性的时候，随着价格的升高，需求量减少比例多得多，而导致总收益变少，在缺乏弹性的时候，随着价格的升高，需求量减少的很少很少，而导致总收益是增大的

## 需求收入弹性

需求收入弹性描述当收入变动时，需求量如何变动

$$需求收入弹性 = \frac{需求量变动百分比}{收入变动百分比}$$
需求的交叉价格弹性：衡量一种物品的需求量对另外一种物品价格变动的反应程度

$$需求的交叉价格弹性 = \frac{物品一的需求量变动百分比}{物品二的价格变动百分比}$$
