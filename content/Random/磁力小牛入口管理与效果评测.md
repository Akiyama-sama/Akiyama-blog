# 磁力小牛入口管理与效果观测

> [!info] 原文
> [需求文档（内网）](https://docs.corp.kuaishou.com/d/home/fcABqrnG9LVhd4o1yMfw-XLfu)
> 页面原型：https://pulse.prt.kuaishou.com/ops/niuEntryOverview

## 1. 功能整体描述

### 1.1 功能说明

在 Pulse「智能运营 > 磁力小牛总览」下建设「入口总览」，将磁力小牛入口的**登记**、**使用观测**和**用户分层分析**集中在一个页面内。页面包含三个工作区：

| 工作区 | 主要用途 | 核心操作 |
| --- | --- | --- |
| 入口健康 | 查看入口整体运行情况 | 查看健康入口、待关注入口、曝光用户数、点击率和采纳率 |
| 诊断工作台 | 查看单个入口的使用结果 | 选择入口，查看使用漏斗、回答反馈、用户分布和数据检查 |
| 入口配置 | 维护入口登记信息 | 新增入口、编辑入口名称、查看入口表现、归档入口 |

入口由「入口场景 `invokeScene` + 入口来源 `entrySource`」联合确定。同一组合只能登记一次，业务页面和磁力小牛上报同一组字段，从而将入口曝光、点击、小牛使用和回答反馈归集到具体入口。

> [!important] 统计目标边界
> 入口效果统计的首要目标是判断知识触点是否有助于减少因页面疑问而发起的客服主动提问。曝光、点击、小牛使用和回答反馈属于**过程指标**，平台提供客观数据，**不自动给出**入口保留、调整或下线结论，也**不自动控制**业务页面入口上下线。

### 1.2 整体操作链路

```text
在入口配置中登记入口
→ 业务页面使用入口场景和入口来源
→ 页面入口及磁力小牛上报统一字段
→ 在入口健康中查看整体运行情况
→ 进入诊断工作台查看单入口漏斗和用户分布
→ 结合客服主动提问变化进行人工复核
→ 决定保留、调整或发起业务下线，并在 Pulse 归档入口
```

Pulse 负责入口登记、数据查询和效果观测。入口在业务页面中的文案、样式、展示条件和发布仍由**业务代码**负责。

## 2. 公共查询与数据范围

三个工作区共用时间、统计维度和入口筛选条件。切换工作区时保留当前条件。

### 2.1 时间范围与统计维度

| 条件 | 规则 |
| --- | --- |
| 昨天 | 查询最近一个完整自然日 |
| 近 7 天 | 查询截至昨天的最近 7 个完整自然日，默认选中 |
| 账户 AID | 所有数量和比例按去重账户计算 |
| 用户 UID | 所有数量和比例按去重用户计算，可继续查看消耗分层和客户分型 |

> [!warning] AID 与 UID 是两套独立统计口径
> 切换维度后，全页数量、比例、漏斗和明细同时刷新，**不将 AID 结果与 UID 结果混合展示**。

### 2.2 搜索与更多筛选

| 筛选项 | 规则 |
| --- | --- |
| 关键词 | 模糊匹配入口名称、入口来源和创建人 |
| 入口场景 | 按 `invokeScene` 筛选 |
| 数据状态 | 按入口数据状态筛选，状态定义见 3.2 |
| 用户分层 | 仅在 UID 维度启用，支持单个消耗分层或客户分型 |
| 清除筛选 | 清空关键词、入口场景、数据状态和用户分层，保留时间范围与统计维度 |

筛选条件变化后，健康指标、入口列表和诊断详情使用同一筛选范围。请求失败时，不使用与当前条件不一致的旧结果，避免数据误读。

## 3. 入口概览

### 3.1 整体概览

入口健康是进入页面后的默认工作区，用于快速确认已登记入口是否持续产生数据，以及当前范围内的总体使用情况。

页面展示数据来源、最近数据时间、入口健康分布以及曝光、点击和采纳情况。点击状态卡片可筛选入口；点击待关注入口可进入诊断工作台。

### 3.2 数据状态

| 状态 | 含义 |
| --- | --- |
| 数据正常 | 当前时间范围内关键事件连续，具备查看效果的基础 |
| 数据不完整 | 已收到部分事件，但关键节点缺失或无法形成完整漏斗 |
| 暂无数据 | 当前时间范围内未收到该入口数据 |
| 久未更新 | 曾收到入口数据，但最近数据时间超过约定更新周期 |

「待关注入口」汇总数据不完整、暂无数据和久未更新三类入口。状态只说明当前数据情况，不代表入口本身无效，也不直接形成下线结论。

## 4. 诊断工作台

### 4.1 单入口使用漏斗与入口表现

左侧选择入口，中间查看漏斗和指标，右侧查看数据检查与入口信息。

#### 漏斗节点

| 顺序 | 节点 | 说明 |
| --- | --- | --- |
| 1 | 符合曝光条件 | 当前页面条件下具备入口展示资格 |
| 2 | 入口曝光 | 入口实际进入用户可视区域 |
| 3 | 点击入口 | 用户完成入口点击或跳转 |
| 4 | 打开小牛 | 磁力小牛面板实际展示 |
| 5 | 发送问题 | 用户问题或入口预置问题成功发送 |
| 6 | 看到回答 | 有效回答首次展示 |

回答反馈作为漏斗后的**独立结果区**展示，不与采纳、不采纳合并为一个漏斗节点。漏斗展示六个使用节点的去重对象数，以及相对上一个节点的转化率。去重对象由页面顶部所选统计维度决定。

### 4.2 入口完整详情

| 模块 | 展示内容 |
| --- | --- |
| 基本信息 | 入口名称、入口场景、入口来源、创建人、创建时间、最后修改 |
| 数据信息 | 数据状态、状态说明、最近收到数据时间 |
| 使用漏斗 | 六个使用节点的去重数量和相邻转化率 |
| 回答反馈 | 反馈率、采纳率、不采纳率、未反馈回答占比及对应数量 |
| 用户分布 | 消耗分层、客户分型及各分层表现 |
| 数据检查 | 入口识别、漏斗完整性、反馈数据等检查项 |

入口详情只展示当前时间范围和统计维度下的数据。切换顶部条件后，再次打开详情时使用更新后的数据范围。

### 4.3 消耗分层与客户分型

用户分布**仅在 UID 维度**展示。抽屉默认显示消耗分层，可切换至客户经营分型。

#### 目标展示指标

| 指标 | 展示要求 |
| --- | --- |
| 用户数 | 当前入口、当前分层的去重 UID 数 |
| 用户占比 | 当前分层用户数占当前入口全部用户数的比例 |
| 曝光率 | 当前分层的入口曝光率 |
| 点击率 | 当前分层的入口点击率 |
| 反馈率 | 当前分层看到回答后提交反馈的比例 |
| 采纳率 | 当前分层看到回答后提交采纳的比例 |
| 不采纳率 | 当前分层看到回答后提交不采纳的比例 |

#### 分层规则

| 维度 | 规则 |
| --- | --- |
| 消耗分层 | 使用 C0 至 C5；没有消耗分层数据的用户计入 C0 |
| 客户经营分型 | 使用当前统一分型枚举；无法识别的用户展示为「未分型」 |

用户占比以当前入口、当前时间范围内的去重 UID 为分母。同一 UID 在同一统计范围内只归入一个分层。

### 4.4 客服主动提问变化

该模块放在入口完整详情的**回答反馈之后、用户分布之前**，用于观察入口使用后是否仍有用户主动提问。

| 信息 | 展示规则 |
| --- | --- |
| 主动提问对象数 | 当前入口关联到的去重 AID 或 UID 数，随顶部统计维度切换 |
| 主动提问率 | 主动提问对象数 / 当前入口看到回答的去重对象数；分母不足时显示暂无结果 |
| 周期变化 | 近 7 天对比前 7 天；昨天对比前一完整自然日 |
| 高频问题类型 | 展示归并后的问题类型、提问用户数和占比 |
| 问题明细 | 在权限范围内展示已脱敏原始问题、AID、UID 和提问时间 |

> [!caution] 周期变化用于发现值得复核的现象，**不直接认定**为入口带来的因果效果。

## 5. 入口配置

### 5.1 入口配置列表

集中展示已经登记的入口，并提供新增、编辑、查看表现和归档操作。入口场景与入口来源用于识别业务数据，配置值必须与业务页面和磁力小牛上报值保持一致。

### 5.2 新增入口

| 中文名称 | 字段 | 必填 | 规则 |
| --- | --- | --- | --- |
| 入口名称 | `entryName` | 是 | 使用便于识别的中文名称，最长 128 个字符 |
| 入口场景 | `invokeScene` | 是 | 可选择已有场景，也可输入新场景；仅支持小写字母、数字和下划线 |
| 入口来源 | `entrySource` | 是 | 仅支持小写字母、数字和下划线 |

保存完成表示入口已经登记，**不代表**当前时间范围内已经产生曝光或小牛使用数据。是否有数据以入口健康中的数据状态为准。

### 5.3 联合唯一性校验

| 场景 | 页面反馈 |
| --- | --- |
| 联合字段已经存在 | 提示该入口场景与入口来源组合已经存在，阻止重复保存 |
| 联合字段未使用 | 保存成功并返回配置列表 |

`invokeScene` 与 `entrySource` 联合构成业务唯一标识，不另设需要业务代码上报的入口标识。

### 5.4 编辑入口

仅**入口名称**可编辑，入口场景和入口来源保持只读。入口语义发生变化时，应创建新的字段组合，并归档原入口。

### 5.5 归档入口

当前截图仍显示「删除」，正式方案统一使用「归档」。归档前需二次确认，并记录操作人和操作时间。

- 归档只改变 Pulse 中的管理状态，业务页面入口仍通过代码和发布流程下线；
- 已归档入口不出现在默认列表中，但配置和历史观测仍可查询；
- 已归档入口保持只读，原联合字段不得重复登记。

## 6. 指标与数据规则

### 6.1 核心指标

所有指标跟随页面顶部所选统计维度计算。选择 AID 时按账户去重，选择 UID 时按用户去重。

| 指标 | 计算口径 |
| --- | --- |
| 曝光率 | 入口曝光去重对象数 / 符合曝光条件去重对象数 |
| 点击率 | 点击入口去重对象数 / 入口曝光去重对象数 |
| 小牛打开率 | 打开小牛去重对象数 / 点击入口去重对象数 |
| 问题发送率 | 发送问题去重对象数 / 打开小牛去重对象数 |
| 回答到达率 | 看到回答去重对象数 / 发送问题去重对象数 |
| 回答反馈率 | 提交采纳或不采纳的去重对象数 / 看到回答去重对象数 |
| 采纳率 | 提交采纳的去重对象数 / 看到回答去重对象数 |
| 不采纳率 | 提交不采纳的去重对象数 / 看到回答去重对象数 |
| 未反馈回答占比 | 未提交反馈的去重对象数 / 看到回答去重对象数 |

> [!tip] 没有反馈 ≠ 不采纳
> 比例展示时同时保留对应数量，避免小样本入口仅凭比例被误读。

### 6.2 客服主动提问口径

- 只统计用户主动输入的问题，系统预置问题、快捷选项、自动欢迎语和固定引导文案不计入主动提问；
- 提问需要保留 AID、UID、提问时间及可关联的入口场景和入口来源，用于按入口和问题类型查看变化；
- 同一问题类型保持稳定的归并口径，避免仅因问法变化造成趋势波动。

### 6.3 数据来源与建设要求

业务页面入口事件和磁力小牛事件必须携带同一组入口场景与入口来源。无法识别联合字段的数据不归入具体入口。

| 数据模块 | 主要内容 | 建设要求 |
| --- | --- | --- |
| 入口配置 | 入口名称、入口场景、入口来源、管理状态及操作记录 | 由 Pulse 统一维护；联合字段创建后保持只读 |
| 业务页面入口事件 | 符合曝光条件、有效曝光、点击或跳转 | 每个事件携带入口场景、入口来源、AID、UID 和事件时间 |
| 磁力小牛使用事件 | 打开小牛、发送问题、看到回答、采纳、不采纳 | 沿用同一组入口字段，并区分系统预置问题与用户主动输入 |
| 客服主动提问 | 清洗后的用户原始提问、AID、UID 和提问时间 | 沿用既有主动提问过滤与同类问题归并口径，按周更新 |
| 用户身份映射 | AID 与 UID 的归属关系 | 保留一个 AID 对应多个 UID 的关系，并按当前所选维度去重 |
| 用户属性 | 消耗分层和客户经营分型 | 与观测周期使用一致的标签快照；缺少消耗分层时归入 C0 |
