# 案例题

三个步骤：
- 看三超（超员、超速、超载）
- 再看人（是否酒驾/醉驾/疲劳驾驶）
- 再看车（准驾不符、车有隐患）


各个常见违法行为的判定区间：

- 中型客车大于19人
- 特殊路段>30km/h （弯道、十字路口等）
- 客货>100km/h
- 20mg/ml<酒精含量<80mg/ml 酒驾，大于80mg/ml醉驾
- A2驾驶大型客车：准驾不符
- 连续开车超过4个小时不休息20分钟：疲劳驾驶

# 安全文明常识

对的关键词：减速、停车、靠右、让行、安全距离、依次、观察
错的关键词：加速、急转、紧急制动、随意、连续鸣笛、紧跟

安全带：减轻乘驾人员伤害（只有这一个作用，其他的都是错的），必须系
安全头枕：保护颈部、支撑头部

危险品：
- 爆炸品：火药、炸药、起爆药
- 易燃固体：火柴、硫磺、赤磷
- 运输：公安批准、了解特性、警示标识

问到**应注意**的时候，先优先全选，然后再排除



# 事故及避险


事故避险题型关键词：爆胎、侧滑、碰撞、制动失效、转向失控。

正确操作：稳方向、抢挂低档、不急转、不急刹。（只有事故无法避免除外，可紧急制动）


转向失控：
- 专项困难：安全停车
- 果断连续踩松制动踏板
- 禁止：紧急制动

碰撞：
- 向碰撞一侧修正
- 车速较高/高速，可先制动
- 正面碰撞侧面躲，不跳车

侧滑：
- 泥泞影响选侧滑
- 前轮相反、后轮相同
- 停车观察、驱动轮下铺石

制动失效：
- 先减档，发动机制动、避险车道、刮擦
- 禁止越二级减档、禁止首先拉紧驻车制动

胎压过高或过低都会爆胎，需要先稳方向再减速、非必要不急刹

问故障：打灯放标人转移、再报警
问着火：不得用水灭车、不得车内等待救援、不得开启发动机罩（隔绝氧气）

# 急救

- 出血先止血
- 中毒先移除毒区
- 烧伤喷冷水
- 动脉近心端
- 抢救昏迷先检查呼吸
- 保鲜膜覆盖伤口
- 三角巾包扎
- 搬运昏迷先开放气道
- 可喝淡盐水
- 不要用软担架
