
# 浏览器

## 常用操作

[浏览器快捷键链接](https://support.google.com/chrome/answer/157179)


- ctrl tab 切换下一标签页
- ctrl w删除本标签页
- shift w 将本标签页放到新的窗口
- 锁定大写 按下 j/k 切换标签页
- ctrl l 定位到地址栏
- ctrl d 收藏网页
- ctrl k 地址栏搜索
# 浏览器的标签页：下载vim插件


- ？ 打开帮助
- f 打开按钮
- t 打开新的空白标签页
- O 混合搜索并在新的标签页中打开
- b 在收藏夹里打开
- gg 转到顶部
- G 转到底部
- H 后退
- L 前进
- yy 复制当前标签的网址
- aa 进入阅读模式

# Windows 

- alt tab 切换应用
- win shift s 截屏
- alt 空格 n 最小化当前窗口 
- win d 最小化所有窗口
# Obsidian
alt+enter 进入光标的文件
# VS Code 中的vim
- i 变为insert模式，在当前光标前插入，I 在当前行的首位开始插入
- a在光标后插入，A 在当前行的最后开始插入
- ctrl c  变为 nomal 模式
- w 移动到下个单词的首部

- e 光标移动到下一个单词的尾部（end）


- b 光标移动到上一个单词的开头（back）
- ge 光标移动到上一个单词的尾部（g是一个前缀符/修饰符，一般是相反含义，这里e就是下一个单词开头，相反就是结尾了）
- o 新增一行，并且进入insert模式 ， O表示在当前行的上一行新增一行，并且进入insert模式
- 光标移动到最后：G 移动到顶部：gg
- y 复制一个词 yank
- yy 复制当前行，p 粘贴到当前光标
* . 重复当前操作
* u 撤销当前操作
* ctrl+r恢复前次操作
* dw 删除单词 delete a word
* cw 改变单词 change a word

* ci 移动到{}中，删除括号里面的内容，并且进入insert模式

* ctrl+v 可视化选择快
* shift+v 可视化选择行*
* gg=G 真个文件格式化
